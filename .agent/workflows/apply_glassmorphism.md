1.  **Load Design Intelligence**:
    -   Read the master skill file: `.agent/skills/glassmorphism_design/SKILL.md`.
    -   Internalize the **Strict Forbidden List** (No Blue/Purple AI gradients, No 1px borders, No Bokeh orbs).
    -   Internalize the **Visual DNA** (Caustic Edges, Editorial Typography, Atmospheric Noise).

2.  **Identify Target**:
    -   If the user specified a file, use it.
    -   Otherwise, identify the currently open or most relevant `.html` / `.css` files (e.g., `quiz-result.html`, `styles.css`).

3.  **Analyze & Plan**:
    -   Read the target file(s).
    -   Identify "Mediocre Elements" to purge:
        -   Standard "Card" classes with simple borders.
        -   Symmetrical, centered container layouts.
        -   Standard `16px` typography or `Inter`/`Roboto` fonts.
        -   Any "Blurple" (Blue/Purple) gradients.

4.  **Execute Transformation**:
    -   **Refactor Layout**: Shift elements off-center. Create overlapping Z-index layers.
    -   **Apply Materials**: Replace borders with `box-shadow` "caustics". Increase blur.
    -   **Update Typography**: Implement the **Editorial Serif** (Headings) + **Tech Mono** (Meta) pairing.
    -   **Inject Atmosphere**: Add the global noise texture and "Location-based" background (e.g., "Obsidian", "Mist").

5.  **Verify Quality**:
    -   Check: Is there a 1px solid border? If yes, **FAIL** -> Fix it.
    -   Check: Are cards symmetrically stacked? If yes, **FAIL** -> Fix it.
    -   Check: Are there floating bohek orbs? If yes, **FAIL** -> Fix it.

6.  **Finalize**:
    -   Save changes.
    -   Report the "Theme Persona" applied (e.g., "Applied 'Kyoto Mist' theme").
