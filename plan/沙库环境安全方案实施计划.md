# 沙库环境安全方案实施计划

## 问题概述

当前系统在以下场景中学生/老师可以直接操作共享的 `mysql_test_db`，存在安全风险：

| 场景 | 入口 | 风险 |
|------|------|------|
| **学生自主练习** | `PracticeService.submitAnswer()` → `SqlValidationService.executeSQL()` | 学生可以 DROP TABLE 删除表、恶意修改数据 |
| **老师AI出题** | `GLMService` 生成题目后验证SQL | AI生成的SQL可能有错误，破坏共享库 |
| **老师AI规范题目** | `GLMService.normalizeQuestion()` | 同上 |

| 场景 | 是否需要沙库 | 原因 |
|------|-------------|------|
| **学生Quiz答题** | ❌ 不需要 | 不直接接触数据库内部 |

---

## 解决方案：沙库环境（Sandbox Database）

为每个需要执行SQL的操作创建独立的临时数据库，用完即销毁。

---

## 架构设计

### 当前架构（共享库）
```
mysql_test_db (共享)
├── 自主练习：所有学生共享同一库
├── AI出题验证：直接在这里执行
└── 风险：恶意SQL会影响其他用户
```

### 新架构（沙库隔离）
```
自主练习阶段（每题独立）：
├── 创建临时库: quiz_sb_practice_{studentId}_{answerId}_{timestamp}
├── 执行 setupSql 创建表和数据
├── 执行学生SQL
├── 验证结果
└── 销毁临时库

AI出题验证阶段：
├── 创建临时库: quiz_sb_ai_{timestamp}_{random}
├── 执行 AI生成的 setupSql
├── 执行 AI生成的 expectedSql 验证正确性
├── 验证通过后保存题目
└── 销毁临时库
```

### 步骤4：实现SandboxDatabaseService

**文件**：`src/main/java/com/example/SqlQuiz/service/SandboxDatabaseService.java`

```java
@Service
@Slf4j
public class SandboxDatabaseService {

    @Autowired
    @Qualifier("sandboxAdminDataSource")
    private DataSource adminDataSource;

    @Autowired
    @Qualifier("sandboxUserDataSource")
    private DataSource userDataSource;

    private static final String SANDBOX_PRACTICE_PREFIX = "quiz_sb_practice_";
    private static final String SANDBOX_AI_PREFIX = "quiz_sb_ai_";
    private static final int DB_NAME_MAX_LENGTH = 64;

    /**
     * 为自主练习创建沙库
     */
    public SandboxContext createPracticeSandbox(Long studentId, Long answerId) {
        String dbName = generateSandboxName(SANDBOX_PRACTICE_PREFIX, studentId, answerId);
        return createSandboxInternal(dbName);
    }

    /**
     * 为AI出题验证创建沙库
     */
    public SandboxContext createAISandbox() {
        String dbName = generateSandboxName(SANDBOX_AI_PREFIX, null, null);
        return createSandboxInternal(dbName);
    }

    /**
     * 内部创建沙库方法
     */
    private SandboxContext createSandboxInternal(String dbName) {
        try (Connection conn = adminDataSource.getConnection();
             Statement stmt = conn.createStatement()) {

            // 创建数据库
            stmt.execute("CREATE DATABASE `" + dbName + "`");
            log.info("Created sandbox database: {}", dbName);

        } catch (SQLException e) {
            throw new RuntimeException("Failed to create sandbox: " + dbName, e);
        }

        // 创建用户连接
        try {
            Connection userConnection = DriverManager.getConnection(
                userDataSource.getUrl() + dbName,
                userDataSource.getUsername(),
                userDataSource.getPassword()
            );

            SandboxContext context = new SandboxContext();
            context.setDatabaseName(dbName);
            context.setConnection(userConnection);
            context.setCreatedAt(System.currentTimeMillis());
            return context;

        } catch (SQLException e) {
            // 清理已创建的数据库
            cleanupSandbox(dbName);
            throw new RuntimeException("Failed to connect to sandbox: " + dbName, e);
        }
    }

    /**
     * 执行setupSql初始化沙库
     */
    public void executeSetupSql(SandboxContext context, String setupSql) throws SQLException {
        if (setupSql == null || setupSql.trim().isEmpty()) {
            return;
        }

        try (Statement stmt = context.getConnection().createStatement()) {
            // 支持多条SQL语句
            String[] sqlStatements = setupSql.split(";");
            for (String sql : sqlStatements) {
                if (!sql.trim().isEmpty()) {
                    stmt.execute(sql.trim());
                }
            }
        }
        log.debug("Executed setupSql in sandbox: {}", context.getDatabaseName());
    }

    /**
     * 在沙库中执行SQL
     */
    public SqlExecutionResult executeInSandbox(SandboxContext context, String sql) {
        SqlExecutionResult result = new SqlExecutionResult(false);

        if (sql == null || sql.trim().isEmpty()) {
            result.setError("SQL语句不能为空");
            return result;
        }

        try {
            if (isSelectQuery(sql)) {
                return executeSelectQuery(context, sql);
            } else {
                return executeUpdate(context, sql);
            }
        } catch (SQLException e) {
            result.setError("SQL执行错误: " + e.getMessage());
        }

        return result;
    }

    /**
     * 执行SELECT查询
     */
    private SqlExecutionResult executeSelectQuery(SandboxContext context, String sql) throws SQLException {
        SqlExecutionResult result = new SqlExecutionResult(false);
        long startTime = System.currentTimeMillis();

        try (PreparedStatement stmt = context.getConnection().prepareStatement(sql);
             ResultSet rs = stmt.executeQuery()) {

            long endTime = System.currentTimeMillis();
            result.setExecutionTimeMs(endTime - startTime);

            // 处理结果集
            ResultSetMetaData metaData = rs.getMetaData();
            int columnCount = metaData.getColumnCount();
            List<Map<String, Object>> data = new ArrayList<>();
            int rowCount = 0;
            final int MAX_ROWS = 1000;

            while (rs.next() && rowCount < MAX_ROWS) {
                Map<String, Object> row = new LinkedHashMap<>();
                for (int i = 1; i <= columnCount; i++) {
                    row.put(metaData.getColumnLabel(i), rs.getObject(i));
                }
                data.add(row);
                rowCount++;
            }

            result.setData(data);
            result.setRowCount(rowCount);
            result.setSuccess(true);
        }

        return result;
    }

    /**
     * 执行UPDATE/INSERT/DELETE
     */
    private SqlExecutionResult executeUpdate(SandboxContext context, String sql) throws SQLException {
        SqlExecutionResult result = new SqlExecutionResult(false);
        long startTime = System.currentTimeMillis();

        try (PreparedStatement stmt = context.getConnection().prepareStatement(sql)) {
            int affectedRows = stmt.executeUpdate();

            long endTime = System.currentTimeMillis();
            result.setExecutionTimeMs(endTime - startTime);
            result.setRowCount(affectedRows);
            result.setSuccess(true);
        }

        return result;
    }

    /**
     * 清理沙库
     */
    public void cleanupSandbox(String databaseName) {
        try (Connection conn = adminDataSource.getConnection();
             Statement stmt = conn.createStatement()) {
            stmt.execute("DROP DATABASE IF EXISTS `" + databaseName + "`");
            log.info("Cleaned up sandbox: {}", databaseName);
        } catch (Exception e) {
            log.error("Failed to cleanup sandbox: " + databaseName, e);
        }
    }

    /**
     * 关闭沙库连接
     */
    public void closeConnection(SandboxContext context) {
        if (context != null && context.getConnection() != null) {
            try {
                context.getConnection().close();
            } catch (SQLException e) {
                log.error("Failed to close sandbox connection", e);
            }
        }
    }

    /**
     * 生成沙库名称
     */
    private String generateSandboxName(String prefix, Long studentId, Long answerId) {
        StringBuilder sb = new StringBuilder(prefix);

        if (studentId != null) {
            sb.append(studentId).append("_");
        }
        if (answerId != null) {
            sb.append(answerId).append("_");
        }

        String timestamp = String.valueOf(System.currentTimeMillis());
        String base = sb.toString();

        // 确保不超过MySQL数据库名长度限制（64字符）
        int maxSuffixLength = DB_NAME_MAX_LENGTH - base.length() - 5;
        if (timestamp.length() > maxSuffixLength) {
            timestamp = timestamp.substring(timestamp.length() - maxSuffixLength);
        }

        return base + timestamp + "_" + RandomStringUtils.randomAlphanumeric(4).toLowerCase();
    }

    private boolean isSelectQuery(String sql) {
        return sql.trim().toUpperCase().startsWith("SELECT");
    }
}
```

### 步骤5：修改PracticeService（自主练习使用沙库）

**文件**：`src/main/java/com/example/SqlQuiz/service/PracticeService.java`

**修改 `submitAnswer` 方法**：

```java
@Autowired
private SandboxDatabaseService sandboxService;

public PracticeAnswer submitAnswer(Long answerId, String studentSql) {
    PracticeAnswer answer = practiceAnswerRepository.findById(answerId)
        .orElseThrow(() -> new RuntimeException("Answer not found"));

    SandboxContext sandbox = null;
    try {
        // 1. 创建沙库
        sandbox = sandboxService.createPracticeSandbox(
            answer.getRound().getSession().getStudent().getId(),
            answerId
        );

        // 2. 执行setupSql初始化数据
        String setupSql = answer.getSetupSql();
        if (setupSql != null && !setupSql.isEmpty()) {
            sandboxService.executeSetupSql(sandbox, setupSql);
        }

        // 3. 处理学生SQL（添加表前缀）
        String actualSql = addTablePrefixToSql(studentSql, answer.getTablePrefix());

        // 4. 在沙库中执行SQL
        SqlValidationService.SqlExecutionResult result =
            sandboxService.executeInSandbox(sandbox, actualSql);

        // 5. 判断是否正确
        boolean isCorrect = result.isSuccess() &&
            (result.getError() == null || result.getError().isEmpty());

        // 6. 更新答案记录
        answer.submitAnswer(studentSql, result, isCorrect,
            isCorrect ? answer.getQuestion().getScore() : 0.0);

        // 7. 如果是错题，更新错误统计
        if (!isCorrect) {
            updateErrorStatistics(answer, result.getError());
        }

        return practiceAnswerRepository.save(answer);

    } catch (Exception e) {
        log.error("Practice answer submission failed", e);
        throw new RuntimeException("答题失败: " + e.getMessage());
    } finally {
        // 8. 清理沙库
        if (sandbox != null) {
            sandboxService.closeConnection(sandbox);
            sandboxService.cleanupSandbox(sandbox.getDatabaseName());
        }
    }
}
```

### 步骤7：添加定时清理任务

**文件**：`src/main/java/com/example/SqlQuiz/service/SandboxCleanupService.java`

```java
@Service
@Slf4j
@EnableScheduling
public class SandboxCleanupService {

    @Autowired
    @Qualifier("sandboxAdminDataSource")
    private DataSource adminDataSource;

    // 每10分钟清理一次超过1小时的沙库
    @Scheduled(cron = "0 */10 * * * ?")
    public void cleanupOldSandboxes() {
        long cleanupTime = System.currentTimeMillis() - (60 * 60 * 1000); // 1小时前

        try (Connection conn = adminDataSource.getConnection();
             Statement stmt = conn.createStatement()) {

            // 查找所有沙库
            ResultSet rs = stmt.executeQuery(
                "SELECT schema_name FROM information_schema.schemata " +
                "WHERE schema_name LIKE 'quiz_sb\\_%'"
            );

            int cleanedCount = 0;
            while (rs.next()) {
                String dbName = rs.getString("schema_name");

                // 从数据库名中提取时间戳判断是否需要清理
                try {
                    String timestampStr = extractTimestampFromDbName(dbName);
                    long dbCreatedTime = Long.parseLong(timestampStr);

                    if (dbCreatedTime < cleanupTime) {
                        stmt.execute("DROP DATABASE `" + dbName + "`");
                        log.info("Cleaned up old sandbox: {}", dbName);
                        cleanedCount++;
                    }
                } catch (Exception e) {
                    // 如果无法解析时间戳，跳过
                }
            }

            if (cleanedCount > 0) {
                log.info("Sandbox cleanup completed: {} databases removed", cleanedCount);
            }

        } catch (Exception e) {
            log.error("Sandbox cleanup failed", e);
        }
    }

    private String extractTimestampFromDbName(String dbName) {
        // 数据库名格式: quiz_sb_practice_123_456_1234567890_abcd
        // 提取时间戳部分
        String[] parts = dbName.split("_");
        return parts[parts.length - 2]; // 倒数第二部分是时间戳
    }
}
```

## 回滚方案

如果出现问题，可以通过以下步骤回滚：

1. 恢复 `PracticeService.java` 中的 `submitAnswer` 方法，移除沙库调用
2. 恢复 `GLMService.java`，移除沙库验证
3. 注释掉 `SandboxDatabaseService` 和 `SandboxCleanupService`
4. 删除沙库数据源配置

---

## 注意事项

1. **性能考虑**：
   - 沙库创建/销毁有一定开销（约100-200ms）
   - 自主练习每题一次，可接受
   - AI出题验证仅在出题时使用，频率低

2. **并发限制**：
   - 设置合理的连接池大小（admin: 5, user: 10）
   - 监控数据库连接数

3. **清理策略**：
   - 定时任务每10分钟清理一次
   - 保留1小时内的沙库
   - 确保不会堆积

4. **兼容性**：
   - Quiz答题不使用沙库，保持原有逻辑
   - 只对自主练习和AI出题启用沙库
